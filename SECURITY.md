# Security Policy

PumpStation Labs is simulation-only. Do not submit real personal financial information, private keys, seed phrases, exchange credentials, investor data, or funds.

Report vulnerabilities through a private GitHub Security Advisory for this repository. Do not include secrets in public issues.

Immediate disarm conditions include:

- a real-money, transaction, transfer, order, custody, deposit, or campaign path;
- replayable identity;
- agent self-approval;
- stage activation without a Kernel permit;
- event-chain alteration;
- deletion of dissent;
- classifier failure that progresses;
- fixture output represented as financial performance.

Current limitations and incident steps are documented in [docs/THREAT_MODEL.md](docs/THREAT_MODEL.md) and [docs/ROLLBACK.md](docs/ROLLBACK.md).
