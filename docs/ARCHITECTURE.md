# PumpStation Architecture

## Product boundary

PumpStation is a bounded UNIIMENTE Venture Cell for community-capital research, productive-asset underwriting, structured deliberation, simulation, evidence, and outcome reconciliation.

It owns:

- community and member-domain state;
- opportunity packets;
- deliberation records;
- simulation proposals;
- participant-impact reviews;
- domain evidence and outcome projections.

It must not own:

- the Constitution;
- canonical legal-principal identity;
- institution-wide capability grants;
- treasury sovereignty;
- the canonical Consequence Gate;
- global causal memory;
- production settlement authority.

Those belong to `dababiyoda/uniimente-kernel`.

## Zero-trust boundary

Wallet control proves only address possession. Production requires authenticated humans and workloads, purpose-limited grants, allowlisted targets, ceilings, expiry, revocation, evidence obligations, and reconciliation.

## Event semantics

Every material event contains actor, subject, origin, environment, reality status, truth status, timestamp, previous hash, and event hash. The current JSON implementation is a sandbox reference and must be replaced with transactional append-only persistence before any pilot.

## Evidence boundary

A README claim, passing unit test, deterministic fixture, sandbox execution, external effect, independently verified outcome, and commercial result are separate evidence tiers. PumpStation may never upgrade one tier by assertion.

## Public launch boundary

Public research is not an investment offering. Real capital, custody, trading, pooled assets, or public solicitation require separate legal, security, operational, and founder gates.
