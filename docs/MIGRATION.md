# Migration from Legacy PumpStation

## Original state

The repository described coordinated memecoin buy-ins and automated exits. Its only substantive implementation was a wallet-signature demo using a static message and MongoDB user record.

## Preserved

- Git history;
- repository identity;
- wallet-signature verification as an identity primitive;
- simple client/server development structure.

## Superseded

- memecoin-coordination doctrine;
- community-driven price-movement framing;
- automated-exit framing;
- static replayable sign-in message;
- untested Next.js scripts for a plain Node server.

## Replacement

- one-time nonce wallet challenge;
- productive-asset opportunity packets;
- anti-manipulation policy;
- five-role, two-pass deliberation;
- founder simulation authorization;
- append-only event history;
- staged public launch;
- explicit UNIIMENTE Kernel boundary.

## Rollback

Close the draft PR or revert its commits. The default branch is unchanged until an authorized merge. Historical source remains available in Git.
